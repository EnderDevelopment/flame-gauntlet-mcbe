# Flame Gauntlet

Flame Gauntlet is a custom Minecraft plugin that adds a unique item called the Flame Gauntlet. This item features three special abilities: a primary action that fires a flame projectile, a sneaking right-click action that triggers a 360-degree fire wave, and a holding action that grants fire resistance. The plugin includes custom particle animations and sound effects for all attacks, enhancing the gameplay experience.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/FlameGauntlet/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Obtain the Flame Gauntlet by using the command `/flamegauntlet`.
2. Right-click to fire a flame projectile from both hands.
3. Sneak and right-click to trigger a 360-degree fire wave around you.
4. Hold the item to gain fire resistance.
